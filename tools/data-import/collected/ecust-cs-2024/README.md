## 人工说明

1. 当前批次只收录 `081200 计算机科学与技术` 一个学术学位专业，目的是先把真实采集、模板落库和来源追溯链路跑通。
2. `discipline_category=工学` 依据专业代码 `081200` 对应学科门类整理。
3. `exam_math_required=true` 依据该专业目录中的统考科目含数学科目整理。
4. `tuition_per_year=8000.00` 依据 2024 招生简章中的全日制学术学位硕士学费标准整理。
5. 本批次未填写招生计划、报录比、复录比、考试科目和参考书，是因为当前采集轮次优先确保“不猜数字、先保真源”。
