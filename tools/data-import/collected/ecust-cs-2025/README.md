## 数据收集流程

### 第1步：收集学校基本信息
- 访问学校官网
- 验证学校层次和类型
- 记录官方来源

### 第2步：收集专业信息
- 访问研究生院网站
- 查找专业目录
- 验证专业代码和名称

### 第3步：收集分数线数据（最关键）
- 等待学校公布复试分数线
- 从官方公告中提取
- 记录精确数字和来源URL
- 人工复核确认

### 第4步：收集招生计划数据
- 查找招生简章
- 提取计划招生人数
- 区分推免和统考

### 第5步：收集报录比数据（如可获取）
- 查找官方统计公告
- 如无官方数据，标记为"待公布"
- 不做任何估计

### 第6步：收集复试要求
- 查找复试录取实施细则
- 提取复试形式和权重
- 记录参考书目

### 第7步：数据验证
- 所有数据经人工复核
- 验证数据来源可追溯
- 标记数据验证状态

## 数据质量要求

### 必须满足的条件
1. ✅ 所有数据有官方来源URL
2. ✅ 所有数字经人工复核
3. ✅ 无猜测或估计数据
4. ✅ 标注数据采集日期
5. ✅ 标注数据验证状态

### 禁止的行为
❌ 编造数字或数据
❌ 使用非官方来源

❌ 导入未验证数据
