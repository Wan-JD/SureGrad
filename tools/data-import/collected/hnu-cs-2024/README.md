## 已知缺口

1. **招生计划**：各专业具体招生人数在招生专业目录 PDF 中，本次在线提取未能访问该 PDF。`program_admissions.csv` 暂缺。
2. **报录比**：官方未在可访问页面中公布报考人数或录取人数统计。`program_application_stats.csv` 暂缺。
3. **学院复试线**：信息科学与工程学院可能在学院级复试方案中设置了高于学校线的学院线（如搜索到的 081200=334、085404=368 等），但学院页面数据以图片形式发布，未能提取验证。本批次只使用学校统一分数线。
4. **083500 软件工程**：湖南大学 2024 年复试分数线公告中未单独列出 083500 学术学位软件工程线，软件工程以方向形式存在于 0854 专业学位下。
