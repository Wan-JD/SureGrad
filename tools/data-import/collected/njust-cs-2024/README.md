## 已知缺口

1. **初试科目**：第四门专业课科目代码未能从官方页面直接确认。2025 年起已改为 408 统考；2024 年可能仍为学校自命题（如 877 或 878），但官方招生目录 PDF 未能在线提取。`program_exam_subjects.csv` 暂缺。
2. **分数线单科线**：学院实施细则未单独列出单科线，学校分数线公告以 PDF 附件发布。`program_score_lines.csv` 暂缺，避免用不确定的单科线填充。
3. **报录比口径**：官方公布"进入复试人数"而非"报考人数"，本批次报录比为复试录取比，非报考录取比。
4. **招生目录**：2024 年招生专业目录 PDF 未能在线解析，学制、学费等信息按常规学术 3 年/8000 元、专业 3 年/10000 元填写，待招生目录确认。
