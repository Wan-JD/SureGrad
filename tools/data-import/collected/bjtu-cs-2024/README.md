## 批次来源

本批次数据来自北京交通大学研究生招生办公室官方发布的 2025 年入学硕士研究生招生专业目录 PDF（2024 年 10 月发布）。

1. 学校：北京交通大学（211/双一流）
2. 院系：计算机与信息技术学院（代码 002）
3. 专业：`081200` 计算机科学与技术、`083500` 软件工程、`085404` 计算机技术、`085410` 人工智能
4. 年份：`2024`（对应 2025 年入学）

## 已知缺口

1. **复试分数线**：未能从官方页面验证 2024 年复试分数线数据。BJTU 研究生院招生通知页面（gs.bjtu.edu.cn/yzzs/）在自动抓取时返回 404 错误。`program_score_lines.csv` 暂缺。
2. **报录比**：官方未在可访问页面中公布报考人数或录取人数统计。`program_application_stats.csv` 暂缺。
3. **学制学费**：招生目录 PDF 中未直接列出学制和学费字段，需要通过招生简章确认。`programs.csv` 中 `duration_years` 和 `tuition_per_year` 暂空。
4. **085405 软件工程**：BJTU 2025 年入学招生目录中未列出 085405 软件工程专业学位。
5. **初试科目确认**：agent 报告专业学位（085404、085410）初试科目也为 201/301（而非通常的 204/302），需人工复核招生目录 PDF 确认。
