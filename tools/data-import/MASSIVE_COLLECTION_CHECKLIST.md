## 3. 数据收集执行规范

### 3.1 每个学校的标准收集流程

**步骤1：访问官方网站**
- 打开学校研究生院官网
- 找到"招生信息"或"通知公告"栏目
- 查找2025年复试分数线相关公告

**步骤2：提取数据**
- 找到目标专业的分数线
- 提取总分和各科目分数
- 提取招生计划数据
- 提取参考书目信息

**步骤3：记录来源**
- 记录完整的URL
- 记录公告标题
- 记录发布日期
- 截图保存关键信息

**步骤4：人工复核**
- 核对所有数字是否正确
- 对比往年数据是否合理
- 检查格式是否统一
- 确认数据完整性

**步骤5：标记验证状态**
- 已验证：official（有官方来源，经人工复核）
- 待验证：pending（已收集，待复核）
- 未验证：unverified（来源不够权威）

### 3.2 数据质量检查清单

**数字类数据检查**：
- [ ] 总分是否合理（通常200-400分范围）
- [ ] 单科分数是否合理（通常30-100分范围）
- [ ] 分数线是否高于国家线
- [ ] 与往年对比是否合理

**文字类数据检查**：
- [ ] 专业名称是否准确
- [ ] 专业代码是否正确
- [ ] 学校名称是否准确
- [ ] 学院名称是否准确

**来源类数据检查**：
- [ ] URL是否可访问
- [ ] 来源是否为官方
- [ ] 采集日期是否标注
- [ ] 验证状态是否标记

## 6. 注意事项

### 6.1 数据准确性要求

**必须遵守**：
1. ✅ 所有数据必须来自官方渠道
2. ✅ 所有数字必须经人工复核
3. ✅ 所有来源必须有URL
4. ✅ 所有数据必须标记验证状态

**绝对禁止**：
1. ❌ 编造数字或数据
2. ❌ 使用估计数据而未标注
3. ❌ 使用非官方来源
4. ❌ 导入未验证数据

### 6.2 数据来源权威性

**优先级1（最高权威）**：
- 学校研究生院官网
- 学校招生办公室官网
- 研招网

**优先级2（高权威）**：
- 学院官网
- 官方新闻发布会
- 官方公告

**优先级3（中等权威）**：
- 权威媒体报道
- 官方公众号
- 教育部门官网

**优先级4（低权威）- 不建议使用**：
- 社交媒体
- 非官方论坛
- 个人博客
- 经验分享帖

### 6.3 异常处理

**数据异常处理**：
1. 数字明显错误 → 标记为verified_incorrect，不导入
2. 来源不可靠 → 标记为unconfirmed，不导入
3. 格式不符合 → 修正后重新验证
4. 数据缺失 → 标记为pending，补充后导入

**来源异常处理**：
1. URL不可访问 → 标记为unverified，寻找替代来源
2. 来源变更 → 更新URL，重新验证
3. 来源删除 → 标记为unconfirmed，寻找存档
