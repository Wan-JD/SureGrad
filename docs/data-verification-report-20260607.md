   - 南京大学（2024年）

### 1.2 核验方法

1. **来源验证**：检查数据是否来自官方渠道
2. **数字验证**：对比官方数据确认数字准确性
3. **逻辑验证**：检查数据是否合理（如分数线范围）
4. **一致性验证**：检查不同来源的数据是否一致
