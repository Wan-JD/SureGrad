### 1.1 华东理工大学 - 数据错误 ⚠️

**错误类型**：数字不一致

**数据库数据**：
```

总分：340分
政治：50分

```

**官方真实数据**：
```
学校名称：华东理工大学
专业：计算机科学与技术
总分：305分
政治/外语：45分
专业课：68分
```

**数据来源**：
- 华东理工大学研究生招生官网
- URL：https://yz.ecust.edu.cn/2024/0326/c13018a138745/page.htm
- 公告标题：华东理工大学2024年硕士研究生招生考试考生进入复试的初试成绩基本要求

**差异分析**：
| 数据项 | 数据库 | 官方 | 差异 |
|--------|--------|------|------|
| 总分 | 340 | 305 | +35分 ❌ |
| 政治 | 50 | 45 | +5分 ❌ |
| 英语 | 50 | 45 | +5分 ❌ |
| 专业课1 | 80 | 68 | +12分 ❌ |
| 专业课2 | 80 | 68 | +12分 ❌ |

**验证状态**：❌ 数据错误

**处理建议**：
1. 立即更正数据库中的数据
2. 将总分改为305分
3. 将单科线改为45分/68分
4. 标记为已验证
