# SureGrad

SureGrad is an Android-first graduate exam preparation app focused on:

- school and program analysis
- score lines, application ratios, and interview ratios
- study planning and execution
- curated learning resources

## Workspace layout

```text
docs/               Product and planning documents
apps/mobile/        Flutter Android app
apps/admin/         Admin dashboard
services/api/       Backend API service
packages/shared/    Shared schemas, constants, or utilities
tools/data-import/  Data ingestion and import scripts
```
